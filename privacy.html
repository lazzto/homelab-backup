Privacy Policy

Last updated: November 5, 2026

HomeLab Backup is a personal backup tool used to manage and store backup files in Google Drive.

Information We Access

The application accesses Google Drive data only to perform backup and file management operations authorized by the account owner.

How We Use Your Data

Google Drive data is used solely for backup, synchronization, and file management purposes.

Data Sharing

We do not sell, rent, or share Google user data with third parties.

Data Security

Access tokens and backup data are stored securely and are used only for the intended backup operations.

Data Retention and Deletion

Users can revoke application access through their Google Account settings. Stored backup files can be deleted by the account owner.
